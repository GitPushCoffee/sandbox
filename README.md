## Hello! Here's what GitHub Copilot Coding Agent can do 🤖

GitHub Copilot Coding Agent is an AI-powered software engineer that works autonomously inside your repository. Here are some of the things it can help with:

### 🛠️ Code Changes
- **Implement new features** — write production-quality code from a description or issue
- **Fix bugs** — diagnose and patch failing code, including hard-to-reproduce issues
- **Refactor code** — improve structure, naming, and organization without changing behavior
- **Add tests** — write unit, integration, or end-to-end tests for existing or new code

### 🔍 Code Understanding
- **Explore codebases** — navigate large or unfamiliar repositories and explain how things work
- **Review pull requests** — analyze diffs, spot issues, and suggest improvements
- **Find security vulnerabilities** — scan code for common security issues (e.g. via CodeQL)

### 📦 Project Maintenance
- **Update dependencies** — bump library versions and resolve breaking changes
- **Improve documentation** — write or update READMEs, inline docs, and API docs
- **CI/CD troubleshooting** — read GitHub Actions logs and fix failing workflows

### 🔗 Integrations
- Works directly with **GitHub Issues and Pull Requests**
- Can read **workflow run logs** and **code scanning alerts**
- Understands your repo's **structure, tests, and tooling** before making changes
